# Ersatzbilder

Ein Bild in diesem Ordner ersetzt das Projektbild aus dem Formular. Dateiname = Projekt-ID, also
`<einrichtung>--<projekt>.jpg` (auch `.png`/`.webp`), z. B.
`zam-zentrum-fuer-austausch-und-machen--reduzierung-zuschuss.jpg`. Die ID steht im Kachel-Link hinter
`/einrichtungen/` bzw. in `src/generated/data.json` unter `id`.

Der Bildnachweis bleibt der aus dem Formular. Datei löschen → wieder das Formularbild.
